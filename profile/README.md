# Happ - Cross-Platform Proxy Client

## About Happ

Happ is a cross-platform proxy client built on the Xray core. Happ helps users manage proxy server connections, organize profiles, and keep routing clear across different operating systems. Whether you need a Happ proxy client for daily browsing or a Happ proxy manager for multiple server profiles, Happ keeps the process readable and predictable. The Happ Xray core provides a stable foundation for connection handling, so users can focus on choosing the right server instead of fighting with configuration files.

If you have ever struggled with scattered proxy tools, Happ cross platform support and Happ server setup simplicity make it a practical choice for managing connections across devices.
